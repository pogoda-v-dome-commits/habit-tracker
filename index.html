Что такое «Второе дыхание»

Не просто список галочек, а инструмент для человека, который хочет постепенно пересобрать свою жизнь через небольшие ежедневные действия. Цель — это ориентир на горизонте, а личность формируется привычками, которые вы повторяете каждый день.

Как начать

Во вкладке «Сегодня» отмечайте привычки, которые выполнили. Список можно менять под себя — добавлять, редактировать, отключать временно, удалять.

Как отмечать привычки

Нажмите на кружок или название — привычка отметится выполненной. Значок карандаша открывает редактирование (название, расписание по дням недели). Значок питания временно включает/выключает привычку без удаления. Стрелки меняют порядок. Корзина удаляет (с подтверждением).

Как вести дневники

Вкладка «Дневники» — три отдельных блока: благодарность, успех, идеи. Записи сохраняются навсегда и не сбрасываются утром, в отличие от чек-листа привычек.

Как пользоваться матрицей

Вкладка «Приоритеты» — распределяйте задачи по четырём квадратам: срочно/важно, важно/не срочно, срочно/не важно, ни то ни другое. Задачи не исчезают сами — отмечайте выполненными, переносите между категориями кружками-точками или удаляйте. Кнопка «Очистить выполненные» уберёт закрытые задачи из списка.

Как смотреть статистику

Вкладка «Статистика» — график за последние 7 дней, среднее выполнение, серия дней подряд на 100% и процент по каждой привычке. В первую неделю среднее считается только по дням, которые уже прошли — не по семи заранее.

Установка на телефон

iPhone: откройте ссылку в Safari → «Поделиться» → «На экран Домой».
Android: откройте ссылку в Chrome → меню (⋮) → «Установить приложение».
