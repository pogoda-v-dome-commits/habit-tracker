# Второе дыхание — трекер привычек

Готовая структура для GitHub Pages. Данные хранятся в браузере пользователя
(localStorage) — у каждого человека, который откроет ссылку, будет своя,
отдельная копия трекера и своих записей.

## Файлы
- `index.html` — само приложение
- `manifest.json` — настройки для установки как приложение (PWA)
- `service-worker.js` — офлайн-работа и кэш
- `icon-192.png`, `icon-512.png` — иконки для домашнего экрана

## Как выложить

### Если добавляете в уже существующий репозиторий («Второе Дыхание»)
1. Создайте в репозитории папку, например `habit-tracker/`.
2. Скопируйте туда все 5 файлов из этого архива.
3. Закоммитьте и запушьте:
   ```
   git add habit-tracker/
   git commit -m "Добавлен трекер привычек"
   git push
   ```
4. Ссылка будет вида:
   `https://<ваш-логин>.github.io/<репозиторий>/habit-tracker/`

### Если делаете отдельный новый репозиторий
1. Создайте репозиторий на GitHub, например `habit-tracker`.
2. Положите все 5 файлов в его корень.
3. В настройках репозитория → Pages → Source: выберите ветку `main` и папку `/root`.
4. Ссылка будет вида:
   `https://<ваш-логин>.github.io/habit-tracker/`

## Как обновлять в будущем
Просто замените файлы (например `index.html`) в репозитории и запушьте снова:
```
git add .
git commit -m "Обновление трекера"
git push
```
Ссылка останется той же самой — обновится содержимое по этому же адресу.
Всем, кому вы её уже отправили, не нужно ничего переустанавливать —
достаточно один раз обновить страницу (или переоткрыть установленное приложение).

## Важно про данные
Так как хранилище — это `localStorage` браузера:
- данные не общие, у каждого человека свои;
- если открыть трекер в другом браузере или в режиме инкогнито — будет пусто;
- если очистить данные сайта в браузере — записи удалятся.

Если в будущем понадобится, чтобы данные синхронизировались между
устройствами одного человека (например, телефон и компьютер), это уже
следующий шаг — потребуется простой бэкенд (например, Supabase или Firebase).
